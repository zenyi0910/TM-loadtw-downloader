# TM-loadtw-downloader

load.tw 自動解鎖 + 下載油猴腳本

## 功能

- 自動從頁面日期提取密碼（MMDD 格式）並填入解鎖
- 自動點擊年齡確認
- 解鎖後右下角出現「⬇ 下載」按鈕，一鍵下載影片/圖片

## 安裝

點擊下方連結，Tampermonkey 會自動彈出安裝視窗：

**[安裝腳本](https://github.com/Jeffrey0117/TM-loadtw-downloader/raw/main/loadtw-downloader.user.js)**

## 搭配使用

- lurl.cc / myppt.cc → 使用 [Jeffrey 的 lurlDownloader](https://github.com/Jeffrey0117/TM-lurlDownloader/raw/main/lurlDownloader.user.js)
- load.tw → 使用本腳本
